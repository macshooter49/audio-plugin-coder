Implementation notes (whichever variant you pick):
  • Preset name Prophet Saw click target opens a native HTML <select> with 5 <optgroup>s and 20 options (matches the existing hidden control). Setting the select updates SYN_OSC_A_WT_PRESET and the visible name swaps to the new preset.

v11 — what changed

  • Contrast lifted to white-on-purple throughout. Active engine pills now have a solid --purple-500 background with #FFFFFF icons/text (not the previous low-contrast purple-on-purple). Same treatment for active FLOW mode, SYNC pill, A/B direction pill, env tabs, ribbon mode dropdown, patch-source tags.
  • Waveforms, envelope curves, filter response, LFO shapes → bright white (#ECE8F2). The voice-meta number style is now the page-wide reference for what "readable" looks like.
  • Knob labels → white (--text-primary) instead of muted gray. Every label under every knob actually reads now.
  • Ribbon row fixed at 138px. No more cut-off. Strip is 44px, controls row gets a full 30px+, voice meta sits at proper rhythm.
  • Filter 1/2 toggle redesigned — two equal-size pills (22×18px), 1 is active solid purple + white, 2 inactive. Click to swap. Removed the cramped chevrons.
  • CROSS column symmetric — fixed row heights via grid-template-rows so A/B + SYNC + 3 knobs all align with consistent gaps.
  • LFO rates are dropdowns — each shows a chevron, click to open rate picker. Same dropdown pattern as the filter.
  • Mod patchbay gets a drag-hint line — "DRAG SOURCE → KNOB · ADD ROUTE" under the routes. Producers see that mod is interactive without a manual.
  • Patch-source tags (L1/L2/L3/ENV) now have solid purple bg + white text — they pop as clickable mod sources.

All 6 engines get right-click browsers (preview above the notes)

  • WAVETABLE — 25+ presets across Analog / Digital / Vocal / Metallic / Experimental + USER (Import WAV, From Sample, From Image PNG, Random Gen).
  • SAMPLE — Pigments-class. Factory library across Drums / Vocal / Instruments / Loops / Texture, USER import + per-chop pull, plus sample-level Settings (Start/End, Loop Points, Velocity Zones) AND a "→ MAKE WT" action that converts the loaded sample to a wavetable.
  • GRANULAR — Clouds / Rhythmic / Evolving / Experimental presets + Source selector (OSC A · Sample · Audio In).
  • SPECTRAL — Freeze & Blur / Morph / Shift / Resynthesis (from Sample / Image / Chop).
  • FM — Classic / Percussive / Metallic / Evolving presets + Algorithm picker (2-op / 3-op feedback / 4-op).
  • NOISE — Color (white/pink/brown/blue/violet/green) + Vintage (vinyl/tape/cassette) + Foley + Shaped.

Function-not-show check (you raised this — answering)

  • Every UI element here maps to a real param or behavior. When we move to code, each of these becomes an APVTS parameter + a JS↔C++ binding. The mockup is faithful to what we'll actually wire.
  • Modulation: 3 LFOs (rate, shape, depth, sync), patchbay routes (source → target × depth), drag-from-source-onto-knob assigns. Right-click any knob to see "ADD MOD →" submenu. All wires up.
  • LFO rates: click the dropdown to open a list (1/64 → 1/32 → 1/16 → 1/8T → 1/8 → 1/4T → 1/4 → 1/4D → 1/2 → 1 bar → 2 bar → 4 bar → 8 bar / FREE Hz). Same dropdown pattern as filter.
  • RIBBON modulatable: any LFO/ENV can drive RANGE/GLIDE/DRIFT/RETURN.
  • FLOW knobs modulatable: TIME/SHAPE/SCATTER/TRAJ/MORPH all live in the mod targets list.
  • CROSS knobs modulatable: FM/RING/MIX are mod targets too — assignable from any LFO/ENV.
