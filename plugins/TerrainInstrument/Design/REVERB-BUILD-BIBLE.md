# Terrain Instrument — Reverb Build Bible (fb275 research)

_From the reverb-research workflow: 16 agents, 9 types + 5 reference plugins. Clean-room; every param DRAMATIC; CPU-friendly._

## Architecture

SHARED FDN CORE (one class, reused by Hall, Room, Basin, Shimmer — and its input-diffusion + damping + bass-crossover sub-blocks reused everywhere): an 8-line Feedback Delay Network. Per sample: 8 fractional (linear-interp) delay reads at mutually-prime lengths L_i; each line runs a one-pole HF-damping LP (Jot: g_i = 10^(-3*L_i/(fs*T60)), pole solved from target HF/LF ratio) plus a low-shelf bass-multiplier at a ~120-600 Hz crossover; the 8 outputs are mixed by an 8-pt Hadamard butterfly (24 add/sub, ZERO multiplies) or Householder (mean-and-subtract, O(N)); write-back = diffused input + matrix output. Front-end: pre-delay buffer -> input bandwidth LP -> 4 series Schroeder allpasses (Dattorro 142/107/379/277 scaled by fs/29761, g 0.75/0.625). Output: decorrelated L/R tap sets + M/S width. Multi-phase LFO (phase i = 2*pi*i/N) modulates the long lines; depth scaled inversely with rate so peak detune stays bounded. All coefficients computed at BLOCK rate on a change-gate, one-pole slewed; delay-length (Size) changes GLIDE ~2.5 ms to dodge the comb-click law. juce::ScopedNoDenormals + a 1e-20 anti-denormal DC in every loop.

PER-TYPE TOPOLOGIES (the parts that vary):
- Hall / Room / Basin: the shared FDN core itself, retuned (Hall = long coprime lines + lush mod; Room = short lines + ER tapped-delay bank + ER/Late crossfade; Basin = dark input LP + bass-safe crossover<1 + deep multi-phase mod + Freeze).
- Plate: Dattorro figure-8 tank (two cross-coupled half-loops, each modulated-allpass -> long delay -> damping LP -> decay-diffusion allpass -> long delay -> cross-feed; 7 alternating-sign output taps per channel) + an ~8-stage Thiran/allpass DISPERSION cascade (highs lead lows) for the steel-plate whip.
- Spring: 2-3 parallel dispersive feedback loops = cascaded STRETCHED allpasses (z^-1 -> z^-K, K = fs/(2*Fc)) confining the chirp below a ~4.3 kHz transition, inside a noise-modulated multitap feedback delay; germanium input saturation; low band optionally decimated to fs/4 (Parker multirate) to cut cost ~3x.
- Digital (Lexicon 224/Griesinger): Dattorro cross-coupled tank but with RANDOM (band-limited-noise, coarsely sub-sample-quantized) modulation on 2 tank allpasses AND 2 output taps; dual-band (Bass/Mid) decay with crossover; optional fixed-point grit/hiss. This is the flagship — give it Random-Vintage as default voicing.
- Vintage: the Digital tank run at a REDUCED internal sample rate (32 kHz '80s / ~24 kHz '70s, which both band-limits AND halves CPU) + bit-quantization halo + soft-clip accumulator saturation + a Shape/gate envelope on the wet.
- Shimmer: shared FDN core with a time-domain dual-tap granular pitch shifter (raised-cosine grain window, 2 offset read taps) placed IN the feedback path (+12 default), plus a DC-blocker + High-Cut that let the octave ladder self-terminate; tiny parallel feed-forward octave send for instant onset.
- Convolution: NON-shared. Non-uniform partitioned FFT (Gardner/Garcia: small head blocks for zero latency, geometrically doubling tail blocks on a worker thread) via juce::dsp::Convolution baseline; ALL IR edits (Size/stretch, Decay window, Reverse, damping, EQ) baked OFFLINE on a worker when a knob settles, then real-time path stays a pure convolution; crossfade convolvers ~30 ms on swap; a modulated-FDN Motion tail defeats the frozen-IR metallic ring.

CPU BUDGET (48 kHz, stereo, one global send instance): Hall/Room/Basin/Shimmer FDN ~80-120 flops/sample = well under 1% of a modern core (Hadamard = no multiplies; block-rate coeffs; linear interp; no oversampling of a linear network). Plate ~tens of flops/sample (one mono tank, 8 allpasses, 14 taps) <1%; the Dispersion cascade is the only add (~8 muls) and gates off at 0. Spring ~300 muls/sample raw, ~1/3 with multirate = low single-digit %. Digital/Vintage same order as Plate; Vintage's reduced-rate core NETS a saving. Shimmer adds ~a dozen ops for the shifter. Convolution: partitioned, ~1-3% for a 1-2 s stereo IR; true-stereo only spins up when Width is high and SHARES input FFTs (L feeds LL+LR, R feeds RL+RR). Global rules: FTZ/DAZ mandatory (denormal tails cost ~6% otherwise); no pow()/exp()/sin() in the audio loop; oversample ONLY the nonlinear stages (Vintage saturation, Shimmer pitch read, Spring drive), never the linear reverb.

## Build order

1. Hall — the shared FDN core lives here; build it first and get it godly (Householder/Hadamard mix, per-line damping, bass crossover, coprime delays, multi-phase mod). Everything downstream reuses this.
2. Room — same FDN core, shorter coprime delays + an ER tapped-delay front-end + ER/Late balance. Cheap add once Hall exists.
3. Plate — Dattorro figure-8 tank (new topology) + Thiran dispersion cascade. First non-FDN engine; proves the allpass-tank path used by Digital/Vintage.
4. Spring — dispersive stretched-allpass chains in a modulated feedback loop (new DSP). Distinct enough to stand alone; validates the dispersion primitive Plate also uses.
5. Digital (Max's favorite) — Dattorro/Griesinger cross-coupled tank + RANDOM (noise) delay-line + output-tap modulation + fixed-point grit. Leverages the Plate tank you already wrote; give it the most polish.
6. Vintage — the Digital/Dattorro tank wrapped in the era-coloration layer (reduced internal SR + bit quantization + saturation + Shape/gate). Reuses Digital's tank almost wholesale.
7. Basin — the Hall FDN core with aggressive input bandwidth LP, bass-safe crossover, multi-phase modulation, and Freeze. Pure reuse of the Hall engine, retuned dark/wide.
8. Shimmer — Hall FDN core + a time-domain dual-tap granular pitch shifter INSIDE the feedback loop. Reuses the core; the pitch shifter is the only new block.
9. Convolution — separate engine entirely (non-uniform partitioned FFT + offline IR bake). Build last; shares no DSP with the algorithmic path, only the front/back UI shell.

## Verify

- **Confidence:** MEDIUM-HIGH. The plan is genuinely DSP-literate: the Jot decay law, Hadamard/Householder mixing, Dattorro figure-8 coefficients, spring stretched-allpass dispersion, and shimmer HF-self-termination are all accurate and correctly attributed. It "maths" at the level that matters. The problems are (1) a real architecture mismatch on Convolution, (2) several load-bearing stability/gain subtleties stated too casually, and (3) CPU flop-counts that are order-of-magnitude right but understate serial-recursion wall-clock and are internally inconsistent. None are fatal; all are fixable in planning. I'd green-light the build with the corrections below folded in.
- **CPU feasibility:** FEASIBLE for one global send instance per type, but the reported numbers are optimistic and internally inconsistent. (a) The FDN and spring cascades are serial sample-by-sample recursions — they cannot SIMD across the feedback, so real wall-clock is higher than the raw flop count implies; the plan only admits this for Shimmer. (b) Self-inconsistent: Hall claims '<1%' while Basin claims '2-4% of a core' for THE SAME core plus a few filters and an 8-phase LFO — Basin's figure (Supermassive-class) is the realistic one; the Hall '80-120 flops/sample <<1%' is an undercount (8 lines × [interp read ~4 + damp ~3 + low-shelf ~5] + 24-add Hadamard + 4 input APs + taps ≈ 150-200 flops/sample). Still trivially <1% of a modern core, so the conclusion survives even though the arithmetic is loose. (c) Spring: 300 muls/sample/ch is right for raw count, but a 300-deep first-order-allpass chain has a serial dependency wall (each stage needs the prior stage's output), so ILP is poor and per-sample latency dominates; 3-6 springs stereo could push mid-single-digit % rather than 'well under 3-5%.' (d) Vintage 'reduced internal SR halves CPU' ignores the anti-alias decimation + anti-image interpolation filters (and added latency) needed to run a 24-32 kHz rail inside a 48 kHz host — those partially offset the saving. Bottom line: whole-plugin budget is comfortable, but stop advertising sub-1% for the recursive engines and reconcile Hall vs Basin.
- **Correction:** Convolution: either (a) drop the non-uniform claim and accept juce::dsp::Convolution's uniform latency, or (b) explicitly plan to write a NUPOLS engine (direct-form first partition for zero latency + FFT partitions doubling on a worker). Do not claim Gardner/Garcia performance from stock JUCE.
- **Correction:** Fold the Hadamard 1/sqrt(N) normalization into the per-line damping gains g_i so the matrix stays truly orthonormal while the butterfly stays multiply-free; document this so a future editor doesn't 'optimize' the scale away and detune the decay.
- **Correction:** Shimmer: make the in-loop high-pass the explicit stability governor for any negative (downward) pitch interval, and cap feedback lower for downshift than upshift. Require the granular grain window to be amplitude-complementary at the splice (two raised-cosine grains summing to unity), and unit-test steady-state loop gain at Feedback=100% for +12, +24, -12, and Dual modes.
- **Correction:** Reconcile CPU accounting: quote one consistent per-line flop budget (~150-200 flops/sample for the 8-line core is realistic) and use the same figure for Hall/Room/Basin/Shimmer. Present the recursive engines as 'low single-digit %,' not '<1%,' to reflect serial-recursion wall-clock.
- **Correction:** Convolution latency: state a single number. If you want true zero-latency, add a direct time-domain first partition; otherwise call it '~256-sample / 5.3 ms low-latency' and stop saying 'zero.'
- **Correction:** Digital/Vintage stability: replace the 'decay x allpass g x damping' loop-gain heuristic with the correct condition — feedback-path magnitude (recirculating delay gain x damping magnitude, allpasses excluded as unity-magnitude) < 1 across frequency; Freeze bypasses damping loss AND mutes input (Basin already does this correctly — mirror it).
- **Correction:** Vintage reduced-rate: budget the decimation/interpolation filters and the added latency; the CPU saving is real but not a clean 'halve,' and the resampling anti-alias LP is part of the vintage band-limiting (feature, not just cost).
- **Correction:** Spring: specify integer-rounded K per stage (document the resulting transition-frequency quantization) and add the band-split/recombine filters to the flop budget; keep FTZ/DAZ mandatory since 300-deep chains are the denormal worst case.
- **Correction:** Anti-denormal: use FTZ/DAZ as the primary mechanism and, if injecting, use alternating-sign dither rather than constant DC in any path lacking a DC-blocker (notably the FDN core at Freeze).
- **Correction:** Replace 'satisfies the Jot absorptive-filter magnitude' with 'approximates Jot absorption with a one-pole whose DC gain equals the target LF loss' — accurate and still cheap.
- **Risk:** juce::dsp::Convolution named as the vehicle for NON-uniform partitioning — it is uniform-partitioned and cannot deliver the claimed head-block/7x behavior
- **Risk:** Convolution 'zero latency' vs '256-sample latency' internal contradiction
- **Risk:** Shimmer near-unity feedback stability under DOWNWARD pitch shift (no HF wall; only the in-loop HP terminates it) is under-specified
- **Risk:** Shimmer granular window overlap-add gain must be amplitude-complementary or loop gain modulates >1 — unstated but load-bearing
- **Risk:** Hadamard 'zero multiplies' + 'lossless' requires 1/sqrt(N) folded into g_i, only obliquely acknowledged
- **Risk:** Digital loop-gain formula multiplies allpass coefficient as if it were a magnitude gain (allpass is unity-magnitude) — conceptually wrong bound
- **Risk:** One-pole LP claimed to 'satisfy Jot absorptive-filter magnitude' — it approximates, not satisfies
- **Risk:** CPU self-inconsistency: Hall '<1%' vs Basin '2-4%' for the same FDN core
- **Risk:** Vintage 'reduced SR halves CPU' ignores decimation/interpolation resampling overhead and latency
- **Risk:** Bit-crush + soft-clip inside the recursive tank risks limit cycles / idle tones at long decay
- **Risk:** Constant 1e-20 DC anti-denormal can bloom in a near-unity FDN loop at Freeze without a DC blocker

## Per-type specs

### Hall

- **Character:** Smooth Hall — dense Hadamard FDN, gentle HF damping (modern glassy concert hall), Random Hall — band-limited-noise mod, decorrelated per-line phase (Lexicon 224/480L living tail), Vintage — coarser mod + darker HF shelf (EMT-250/224-era warmth), Cathedral — very long lines + long RT60 + strong low bloom, Chamber — shorter coprime lines, faster density buildup, tighter/brighter, Dark / Warm — heavy HF damping + low-pass tilt, felt distant tail, Bright / Modern — low damping, extended highs, clean matrix, airy pop hall, Ethereal / Wash — max diffusion + deep slow mod + near-infinite decay for pads
- **2nd dropdown:** Mod Mode — the hall-defining axis (Off = purest/most metallic for percussive tails · Subtle = single ~0.2 Hz drift · Lush = multi-LFO per line, default concert-hall chorusing · Chorale = deeper/faster for pad shimmer · Random = per-line band-limited noise, the Lexicon Random-Hall gold standard · Chaos = deep+fast special-effect wobble). Runner-up axis = Quality/Lines (8/12/16).
- **Front (3+Mix):** Size — scales all FDN + diffuser delay lengths together (ensemble hall -> vast cathedral); glides to avoid comb clicks, Decay — RT60 via per-line loss g_i (~0.3 s to 20 s, freeze at max), Tone — one tilt over the wet (dark<->bright: HF damping + high-cut move together), Mix — equal-power dry/wet; 100% fully wet for send/bus
- **Algorithm:** The 8-line shared FDN core, voiced long: pre-delay -> input bandwidth LP -> 4 series Schroeder allpasses -> 8 mutually-prime delay lines each with a one-pole HF-damping LP and a low-shelf bass-multiplier, recombined through a Hadamard (or Householder) lossless matrix so echo density builds smoothly with time exactly like a real room. Decay comes from per-line loss g_i = 10^(-3*L_i/(fs*RT60)); frequency-dependent RT60 from the per-line LP satisfies the Jot absorptive-filter magnitude. Multi-phase per-line modulation (phase-offset LFOs or band-limited noise) continuously detunes the recirculating modes so they never lock into a metallic ring — the single audible difference between a cheap box and a Lexicon. Decorrelated output taps + M/S give the wide stereo image.
- **CPU:** ~80-120 flops/sample stereo, <1% of a core. Hadamard = zero multiplies; block-rate coefficients (no per-sample pow/exp); linear interpolation; process mono-in and decorrelate only at the output taps when the voice is mono; FTZ/DAZ mandatory; never oversample a linear reverb.
- **Viz:** Core-world = a top-down hall footprint whose walls push OUT as Size rises and a decaying energy cloud whose brightness/length tracks Decay and High Damping; the tail waveform visibly WOBBLES (amplitude of the wobble = Mod Depth, frequency = Mod Rate). Pre-Delay draws a gap between the dry impulse marker and the bloom onset. Width spreads the cloud L/R. Every knob move must animate its element.
- **Back 8:**
  - **Pre-Delay** — Delays wet onset after the dry hit, cueing room size. 100% (250 ms) leaves the dry fully naked for a quarter second then the whole hall blooms in as a separate 'other room'. _(range 0-250 ms (tempo-syncable))_
  - **Diffusion** — Input-allpass g + stage count. 0% = discrete machine-gun echoes you can count; 100% = perfectly glassy seamless wash with zero individual echoes. Grain->glass flip. _(range 0-100% (g ~0.0-0.78))_
  - **Mod Depth** — Per-line delay excursion. 0% = static/can ring metallic; 100% = deep seasick chorusing, the tail visibly detunes and shimmers. _(range 0-100% (0 -> ~20 samples))_
  - **Mod Rate** — Speed of the per-line decorrelated mod LFOs/noise. Min = glacial air drift; 100% = fast unmistakable vibrato/chorale warble on the reverb. _(range 0.05-5 Hz)_
  - **High Damping (Air)** — One-pole LP in each feedback path -> frequency-dependent RT60. 0% = highs ring near-forever; 100% = highs vanish instantly, dark distant cavern. Crystal->felt. _(range 0-100%)_
  - **Low Decay** — Bass-multiplier below a ~400-600 Hz crossover, independent of main decay. 100% (~2x) = thunderous rolling cathedral rumble that outlasts everything; min (~0.25x) = tight lows under a singing tail. _(range 0.25x-2x of main decay)_
  - **Low Cut** — High-pass on the wet (also tames loop bass buildup). 100% (~1 kHz) strips all warmth to a thin hovering-above-the-mix reverb; 0% keeps full body and sub. _(range 20-1000 Hz)_
  - **Width** — Stereo decorrelation of the wet (independent L/R output taps). 0% = dead-center mono point source; 100% = ultra-wide wrap-around field (Lexicon 3-D imaging). _(range 0-100%)_

### Room

- **Character:** Neutral Room — balanced damping, moderate diffusion (default believable studio space), Dark Room — heavy HF damping, carpeted/soft-furnished, treble dies fast, Bright Room — low damping + slight HF lift on early taps, tiled/hard walls, lively, Wood / Boxy — fewer stronger early taps + low-mid resonance, short T60, audible box, Chamber — very short coprime delays, high density, tight/intimate, Ambience — sparse taps, very short tail, glue/air that widens without an obvious tail, Plate-tinged Room — denser nested allpasses + brighter damping, snare/vocal hybrid
- **2nd dropdown:** Room Model — loads a distinct early-reflection tap geometry + FDN delay-ratio set (the discrete ER fingerprint is what makes a reverb sound like a SPECIFIC space, an axis orthogonal to Character's tonal color): Vocal Booth · Small Studio · Drum Room · Live Room · Garage/Concrete · Stairwell · Tiled Bathroom · Wood Chamber. Size then scales the chosen fingerprint. Runner-up = Mod Sync (Free vs tempo).
- **Front (3+Mix):** Size — scales every ER tap time AND FDN delay length by a common factor (booth -> large live room), repositioning the reflection pattern, Decay — T60 of the late field via recomputed per-line g_i (tight slap -> long room bloom), Tone — bipolar dark<->bright: left raises low-cut + damping, right lowers damping + adds HF air, Mix — equal-power dry/wet
- **Algorithm:** Two stages in series, ER-forward by design: pre-delay -> input HPF -> 3-4 Schroeder input allpasses that split into (A) an early-reflection tapped-delay bank whose tap times/gains encode the room fingerprint (different L/R tap sets for width) and (B) a late 8-line Householder FDN with SHORT coprime delays (~8-60 ms) and per-line HF-damping LPs. A room is defined by loud, early, closely-spaced reflections plus a short quickly-damped tail, so most energy sits in the ER stage and the FDN stays short and quiet; the Reflections knob crossfades A vs B. Antiphase pitch-preserving modulation on the long lines keeps the comb notches wandering so it never rings. Size scales both stages together; T60 from g_i = 10^(-3*L_i/(fs*T60)).
- **CPU:** Freeverb/Schroeder class — a few hundred flops/sample, well under 0.5% of a core. O(N) Householder via the sigma trick, power-of-two masked buffers, precomputed g_i/damping/tap gains, linear interp, block-rate LFO, one shared instance on the FX bus. No oversampling.
- **Viz:** Core-world = a room box that resizes with Size, discrete ER tap spikes drawn as vertical lines whose spacing tracks Size and whose height vs the tail cloud tracks the Reflections balance (spikes dominant -> boxy; cloud dominant -> hall). Damping darkens the cloud, Bass Decay grows a low-frequency underlay, Width spreads L/R. Mod Depth wobbles the tail. Move a knob, its element moves.
- **Back 8:**
  - **Pre-Delay** — Delays the whole wet vs dry (ms or synced). 100% = obvious silent gap, source stays up-front while the room answers late (vocal-clarity trick). _(range 0-120 ms (or 1/64-1/4))_
  - **Damping** — Per-line LP pole. 100% = all treble stripped almost instantly, dark/muffled like the room is packed with sofas; 0% = glassy sizzling tail. _(range 0% (hard tile) - 100% (curtains/foam))_
  - **Diffusion** — Input-allpass coefficient + active stage count. 0% = fluttery grainy separate reflections (gated-drum character); 100% = perfectly smooth room, no discrete echoes. _(range 0-100% (g ~0-0.75))_
  - **Reflections** — Crossfades ER tap bank vs late FDN tail — THE knob that defines room vs hall. 100% = pure slap-back walls, boxy close room; 0% = amorphous tail, down-the-hall. _(range 0% tail-only -> 100% ER-only)_
  - **Bass Decay** — Low-band decay multiplier below a crossover. High = booming low tail sustains past the mids; low = tight controlled lows. _(range 0.25x-2x, crossover 200-800 Hz)_
  - **Low Cut** — High-pass on the wet + pre-network to stop loop bass buildup/mud. Pushed up = thin airy reverb; low = full body/sub. _(range 20-1000 Hz)_
  - **Mod Depth** — Per-line antiphase pitch-preserving mod. 100% turns a ringing metallic tail into a lush moving wash; 0% can clang on short sources. _(range 0% (static) - 100% (+-8 samples @ ~0.5-2 Hz))_
  - **Width** — M/S scaling of the wet (ER + late fed decorrelated). 0% = mono center; 100% = fully decorrelated hard-wide, room wraps the head. _(range 0-100% (mono -> wide))_

### Plate

- **Character:** Steel (EMT-140) — DEFAULT: warm-dark tank, instant dense diffusion, HF rolls off fast, synthetic centered-wide stereo, Chrome — bright hi-fi modern plate, extended shimmering highs, glassier, more dispersion, Gold / Tube (EMT valve) — gentle input drive + high-shelf roll-off, thicker mids, warm/forgiving on vocals, Brass / Bronze — mid-forward vintage, looser detuned allpasses, faster decay, characterful honk, Aluminum — small/fast, quick metallic ping/boing, short bright tail, great on drums/plucks, Cobalt / Unobtanium — impossible huge dense tank, deep mod, dark ambient wash for pads/cinematic
- **2nd dropdown:** Mod Sync — drives the plate's tank-chorus + predelay clock: Free (~0.05-5 Hz, ~0.8 Hz default plate wobble) | tempo divisions 1/1 · 1/2 · 1/4 · 1/8 · 1/8T · 1/16 (straight/dotted/triplet). A plate's signature movement is slow tank modulation, so making that clock musical is the highest-value discrete choice; oversample (fixed 2x internally) and IR-select are N/A here.
- **Front (3+Mix):** Space — one-knob size+time: scales all diffuser/tank delay lengths AND pushes tank decay (tight nearfield -> cavernous 15 s+ bloom), Tone — dark<->bright tilt: input bandwidth + tank HF damping + subtle output shelf (felt-dark EMT -> chrome endless shimmer), Lush — movement+air: raises tank chorus depth + dispersion + diffusion together (static/metallic -> wide detuned 3-D wash), Mix — equal-power dry/wet, 100% wet return
- **Algorithm:** Dattorro's plate-class reverberator: input sums to mono -> predelay -> input bandwidth LP -> 4 series input allpasses (142/107/379/277 @29761, g 0.75/0.625, scale by fs/29761) -> a cross-coupled FIGURE-8 tank whose two halves each run [modulated allpass ~672/908, g=-0.70] -> long delay -> damping LP -> [decay-diffusion allpass 1800/2656, g tracks decay] -> long delay -> x decay into the OTHER half. Stereo is synthesized at 7 alternating-sign output taps per channel reading across both halves. Plates sound like plates because energy fills the sheet and reflects off the edges INSTANTLY (no discrete early reflections, only a wall of diffusion from t=0) and because bending-wave speed rises with frequency so highs arrive ~10 ms ahead of lows — reproduced by the instant-density tank plus the added Thiran DISPERSION cascade. The two modulated allpasses (~1 Hz, +-16 samples) keep it from ringing metallic.
- **CPU:** The smallest good-sounding reverb known: ~145 KB float for one mono tank, tens of flops/sample, <1% for a stereo instance. One mono tank (stereo synthesized free at the taps), power-of-two masked buffers, block-rate LFO, integer taps except the modulated reads (linear interp). Dispersion cascade (~8 muls) gates off at 0. Offer 2x oversample only as a hidden quality switch for the Tube voice's saturation.
- **Viz:** Core-world = a vibrating steel sheet: Size changes the sheet's dimensions and modal spacing, Dispersion draws a visible frequency-swept chirp (highs racing ahead), HF Damping darkens the sheet's glow, Mod Depth ripples/detunes the surface, Decay sets how long the glow persists (Freeze = eternal steady glow). Pre-Delay = gap before the sheet lights up. Every knob animates the sheet.
- **Back 8:**
  - **Decay** — Tank feedback coefficient = length. 100% snaps to Freeze/infinite — a self-sustaining wash / frozen drone-hold that never dies. _(range 0.4-20 s, then Freeze)_
  - **Size** — Multiplies every diffuser + tank delay. Min = tight bright pingy metallic 'boing' (you almost hear pitch); Max = vast slow smooth dark plate. Whole texture transforms. _(range 50-200% (x0.5-2.0))_
  - **HF Damping** — In-tank one-pole LP (tracks input bandwidth). 100% = pitch-black felt tail, all sparkle stripped; 0% = glassy shimmer that rings forever. _(range Bright (~0) -> Dark (10 kHz gone <0.4 s))_
  - **Dispersion** — Amount in the ~8-stage Thiran/allpass cascade giving frequency-dependent group delay (highs lead lows). 0% = flat generic digital verb; 100% = strong bright swept 'boing'/sheen — THE knob that makes it a steel plate. _(range 0-100%)_
  - **Diffusion** — Input + tank allpass g. 0% = sparse fluttery grainy, individual delays ticking; 100% = seamless glass wall of instant density. _(range 0-100% (g ~0-0.8))_
  - **Mod Depth** — LFO excursion on the two modulated tank allpasses. 0% = frozen, exposes metallic ping; 100% = seasick shimmering detuned chorus, tail visibly swims (Little-Plate style). _(range +-0 -> +-32+ samples)_
  - **Pre-Delay** — Gap before the plate blooms (syncable via Mod Sync). 100% = long obvious slap gap, dry hit stays bone-dry then the plate crashes in behind it. _(range 0-200 ms (or synced))_
  - **Low Cut** — High-pass on the wet (EMT low control), also shortens LF decay. 100% = thin airy telephone-y wet floating far behind the source; 0% = full deep chest-thumping bloom. _(range 20 Hz-1 kHz)_

### Spring

- **Character:** Surf 2-Spring — long dual-spring Fender tank, bold lows, big spaced drippy boings (THE classic), Amp 3-Spring — blackface long 3-spring, denser/smoother, the built-in-amp voice, Studio 3-Spring — low-tension pro tank, lush/dense/refined, minimal metallic ring, Cheap 2-Spring — short high-tension unit, fast bright metallic drip, rattly, Outboard Tube — Fender 6G15 / Grampian 636, germanium-warmed, compressed, drippy surf, Long Pipe 6-Spring — huge multi-spring pipe tank, deep cavernous modulated wash, Lo-Fi Broken — extreme dispersion, detuned springs, exaggerated cartoon boing for FX
- **2nd dropdown:** Springs — parallel spring count: 2 / 3 / 4 / 6. More springs = denser, smoother, more comb-y interference; each line is slightly detuned (Td/Fc +-3-8%). Direct precedent in Softube/PSP; cheap because allpass loops are cheap.
- **Front (3+Mix):** Dwell — global tail super-macro over both feedback gains (toward the edge of self-oscillation) + loop damping (one short splash -> near-infinite drone-ring), Tone — bright<->dark tilt: feedback-path damping LP + tilt shelf (muffled tubby boing -> brittle zingy metallic sparkle), Boing — signature super-macro: dispersion depth + Shake turbulence + Drive together (clean plate-like verb -> maximum drippy cartoon 'boinnng' on every transient), Mix — equal-power dry/wet, default ~25-35%
- **Algorithm:** Valimaki-Parker-Abel parametric spring: two parallel dispersive feedback loops (low-chirp + weaker high-chirp, cross-coupled). The core element is a STRETCHED allpass chain — a first-order allpass whose z^-1 is replaced by z^-K, K=fs/(2*Fc), cascaded ~100 (low) / ~200 (high) times — giving frequency-dependent group delay so an impulse smears into the descending 'boing' chirp. A noise-modulated multitap feedback delay (Td~56 ms, g~-0.8) re-injects delayed+dispersed copies = the repeating boings; leaky-noise delay modulation (~+-8 samples) is NON-OPTIONAL — it jitters the delay every sample so the comb blurs into a tail instead of ringing metallic. A resonator EQ humps energy low (~95 Hz) like a real tank; the high band sits ~60 dB down. Germanium input saturation + a Shake burst complete the amp-tank character. Parallel springs = summed detuned loop instances.
- **CPU:** ~300 muls/sample/channel raw (100+200 first-order allpasses, 1 mul each in transposed DF-II), ~1/3 with Parker's multirate trick (decimate the low band to fs/4). Full stereo, 3 springs, both bands = well under 3-5% of a core. Denormals are the real hazard in the long chains — FTZ/DAZ + -120 dB DC inject; 2x oversample only the Drive nonlinearity.
- **Viz:** Core-world = coiled springs (count = Springs dropdown) that visibly stretch with Time/Tension and, on every input transient, launch a bright frequency-swept chirp down the coil (Transition sets how far up the chirp reaches). ### Digital

- **Character:** Concert Hall B — the flagship 224 hall: low initial density that BUILDS into a huge lush chorused wash (DEFAULT — this is THE Max sound), Small Concert Hall A — brighter, faster density build, tighter than Hall B, Large Concert Hall B — longest tails, lowest coloration (add diffusion to avoid grain on transients), Vocal Plate — bright, clear, forward, high initial density, keeps the source up front, Percussion Plate A — dense/fast attack, slight metallic plate ring, smooth on drums, Constant Density Plate — even (non-building) density, metallic, ideal for gated-80s drums, Acoustic Chamber — less initial density, near-mono core, small-ambience color, Room A — high initial density, minimal coloration, lively fast modulation, Chorus (hidden 9th) — 8-voice / 4 stereo pairs of modulated delays, little feedback: thick detuned widener
- **2nd dropdown:** Chorus Voicing — the 224's SOUL is its time-varying-delay chorusing, so this differentiates more than any oversample/IR menu could: Random-Vintage (noise-driven, coarsely sub-sample-quantized + tiny hiss = the authentic grainy 224 shimmer halo — DEFAULT) · Sine (smooth Dattorro sinusoidal, cleaner modern swirl) · Ensemble (8-voice/4-pair deep detune, widest/thickest) · Wow/Drift (very slow random pitch drift for evolving ambient tails) · Off (static tank — colder, metallic, tighter). - **Front (3+Mix):** Space — morphs size + pre-delay + diffusion together (tiny booth -> cathedral), driving all tank/diffuser delay lengths, Time — reverb decay / tail length (short slap -> infinite freeze), trading a touch of damping in for realism at the top, Chorus — THE flagship 224 macro: modulation depth + rate together (clean/still -> deep seasick shimmering wash). - **Algorithm:** The Lexicon 224 is an allpass-loop / cross-coupled figure-8 tank (Griesinger; canonical clean-room via Dattorro), NOT an FDN or convolver. Chain: pre-delay -> input bandwidth LP -> 4 series input diffusers (142/107/379/277) -> a cross-coupled tank whose two mirror halves each run [modulated allpass 672/908] -> long delay -> damping LP -> x decay -> decay-diffusion allpass 1800/2656 -> long delay -> cross-feed to the OTHER half; 7 alternating-sign output taps per channel read from both halves for wide decorrelated stereo. Its soul is TIME-VARYING delays: modulate 2 tank allpasses AND 2 output taps with RANDOM (band-limited-noise, coarsely sub-sample-quantized) motion so the eigentones never settle — the metallic modes dissolve into the lush seasick 'chorused' shimmer that IS the 224. Modulate delay LENGTH/tap position, never allpass coefficients (coeff-mod itself sounds metallic). Dual-band Bass/Mid decay + crossover gives the booming-lows-under-faster-mids signature; optional fixed-point grit/hiss + linear-interp HF droop supply the vintage warmth. - **CPU:** Very cheap, target under Serum's own reverb: ~6-8 allpasses + ~8-10 taps + 3-4 one-pole filters = a few dozen MAC/sample/channel. No FFT, no oversampling of the linear core. Oversample only an optional soft-clip/drive stage.
- **Viz:** Core-world = the 224's twin cross-coupled tanks drawn as two interlocked figure-8 loops; the recirculating energy visibly SWIRLS and detunes with Chorus/Mod (Random-Vintage adds a grainy noise shimmer to the motion), density BUILDS over time (sparse->dense) per Space, Treble Decay darkens the loop glow while Bass Decay leaves a low underlay ringing on, Size stretches the loops. The 7 output taps fan into a wide stereo field with Width. Give this viz the most care — every Digital knob must move it.
- **Back 8:**
  - **Pre-Delay** — Gap between dry hit and reverb onset (before input bandwidth). 100% = reverb clearly DETACHED, source stays dry-punchy then the wash arrives; syncable. _(range 0-200 ms (or 0-1/2))_

### Vintage

- **Character:** 1980s — DEFAULT 'money' color: fuller bandwidth with a subtle metallic sheen, moderate 12-16 bit grit, brighter lush tail (Lexicon 224X/PCM70, AMS RMX16, REV7), 1970s — darkest: lowest internal SR, 12-bit quantization halo, heaviest damping + mod noise (EMT-250 / early 224), Now — coloration bypassed: full-band clean modern reference tail, 224 Hall — long spacey diffuse dark-modulated (Lexicon 224 large hall), 250 Plate — bright dense fast-building metallic (EMT-250), RMX Ambience — short gritty punchy early-reflection-heavy room (AMS RMX16)
- **2nd dropdown:** Space / Mode — the reverb topology (Character sets WHEN/era, this sets WHERE): Concert Hall · Bright Hall · Plate · Room · Chamber · Ambience · Nonlin/Gated. Each re-tunes delay lengths, diffusion, damping and mod over the SAME engine so it stays CPU-flat (mirrors ValhallaVintageVerb Mode + LX-24 algorithm). Runner-up = Internal Rate/Bit Depth (24k-12bit / 32k-14bit / 48k-16bit / Full).
- **Front (3+Mix):** Time — loop feedback gain / T60 from a 0.2 s room to a 20 s+ frozen wash (freeze at max), Tone — global bright<->dark tilt via the in-loop damping LP + input band-limit, Size — scales all delay/allpass lengths (tiny slap box -> cavernous cathedral), changing modal density + pre-echo spacing, Mix — equal-power dry/wet, sits musically 15-40% for sends
- **Algorithm:** A classic Dattorro/Digital-style tank (reuses the Digital figure-8 tank almost wholesale) wrapped in an era-coloration layer that IS the identity. The engine runs at a REDUCED internal sample rate (32 kHz '80s / ~24 kHz '70s) which simultaneously band-limits like the 20 kHz-sampling 224 hardware AND halves CPU; the loop reads/feedback are re-quantized to 12-16 bits (a signal-correlated 'halo'), the modulated fractional reads are quantized to ~1/32-1/64 sub-sample (zipper/halo noise on moving delays), and the accumulator is soft-clipped (tanh/cubic) to model the 20-bit saturating accumulator that gently overloads and thickens long tails. Slow LFO modulation on the LONG allpasses only (short input allpasses stay near-static to avoid water-sloshing) keeps it from ringing. A Shape envelope on the wet gives gated/reverse 80s tails; a separate LF crossover multiplier gives the Bass Offset bloom. Era maps SR + quantization + noise + damping.
- **CPU:** A handful of allpasses + delay lines + one-pole filters, comfortably <1% for one instance. The reduced-rate core is BOTH the CPU saving and the vintage tone (same move). Block-rate coeffs, recursive LFO, branchless floor+scale bit-crush, cheap poly saturation, Householder O(N). Do the coloration INSIDE the band-limited rail so folded content is filtered on upsample; oversample nothing extra.
- **Viz:** Core-world = the tank rendered through a lo-fi CRT: Grit visibly pixelates/adds a quantization halo + noise fizz to the decaying cloud, Tone/Time set brightness/length, the era Character re-tints it (1970s dark+grainy, Now clean). Shape draws the wet envelope contour (gate cliff or reversed swell). Bass Mult grows a low underlay. Mod wobbles the tail. Every knob moves the CRT image.
- **Back 8:**
  - **Pre-Delay** — Delays wet vs dry (syncable). 100% = long obvious slap gap, dry hits first then the reverb blooms a beat later, clearly detached. _(range 0-250 ms (or 0-1/4))_
  - **Diffusion** — Allpass g in the input + decay diffusers. 0% = sparse grainy fluttering early-digital stutter; 100% = glassy seamless ultra-dense smear. _(range 0-100% (g 0.4-0.78))_
  - **Bass Mult** — Independent LF feedback multiplier below a crossover (the 224 Bass Offset). 100% = huge booming sub-heavy low tail sustains past the mids; low = tight thin controlled lows. _(range 0.25x-2.5x, crossover 200 Hz-1 kHz)_
  - **Mod Depth** — Depth of the slow LFO on the long tank allpasses (de-chromes metal + adds chorus). 0% = static metallic ringing; 100% = seasick detuned underwater warble on the tail. _(range 0-100% (+-0 to ~20 samples))_
  - **Mod Rate** — Speed of that mod LFO. 100% = fast vibrato/warble with obvious pitch wobble; slow = a gentle drift that just keeps the metal off. _(range 0.05-5 Hz)_
  - **Grit** — THE vintage-artifact amount: lowers internal bit depth (quantization halo) AND pushes saturation into the feedback accumulator together. 100% = crunchy noisy overloaded lo-fi tail with an obvious halo + fizz; 0% = clean. _(range 0-100% (16-bit clean -> ~8-bit + soft-clip))_

### Basin

- **Character:** Pool — small-medium basin, dense fast diffusion, gentle multi-phase shimmer (default watery Basin), Lake — large, long RT60, slow deep modulation, very wide and glassy, Cavern — huge dark space, long pre-delay, heavy HF damping, Canyon — very long, pronounced early slap melting into a wide wash, Well — small deep focused/narrow, fast tight modulation (mono-leaning), Grotto — mid size, brightest of the set, prominent chorused shimmer, Tide — evolving/swelling modulation, slow depth breathing for pads, Abyss — near-infinite darkest tank, extreme slow mod, drone/freeze-friendly
- **2nd dropdown:** Mod Shape — Basin's identity IS its modulation, so this reshapes the delay-line LFO (more character-per-click than oversample/IR, which don't apply to a light algo reverb): Sine (smooth multi-phase chorus, default) · Triangle (linear warble, more obvious pitch wobble) · Random/Drift (smoothed per-line noise, organic seasick non-repeating wander) · Dual (two detuned LFOs per line, thick ensemble/detune) · Sync'd (tempo-locked mod 1/1-1/16 for rhythmic swells). Runner-up = Mod Sync (Free vs Tempo).
- **Front (3+Mix):** Size — scales the whole delay-line set (small pool -> vast basin), shifting modal density + pre-echo spacing, Decay — late-FDN RT60 via g_i = 10^(-3*L_i/(fs*T)) (short ambience -> near-infinite), Motion — one-knob depth (+ a touch of rate) of the multi-phase delay modulation (static/metallic-prone -> lush watery chorus + width), Mix — equal-power dry/wet
- **Algorithm:** The shared 8-line FDN core, voiced DARK/WIDE/MODULATED and bass-safe: pre-delay -> wet low-cut HPF + bandwidth LPF (half of why it's dark) -> 4 input allpasses -> 8 mutually-prime lines each with a one-pole HF-damping LP (aggressive) and a low-shelf/crossover bass multiplier <1 -> Hadamard mix -> decorrelated L/R taps + M/S width. Basin sounds like sound settling in a deep dark pool: dark from the input LP + strong per-line damping, wide from decorrelated taps + multi-phase modulation (phase i = 2*pi*i/N, which reads as width not vibrato), watery from the per-line chorusing that also masks the low modal density, bass-safe from the send low-cut + loop bass-multiplier so pads/bass can be soaked without mud, ambient from high diffusion + long decay. Freeze pins loop gain to 1.0 with input muted for an eternal wash. Only an orthogonal matrix is guaranteed lossless before g_i; clamp loop gain <1 except in Freeze.
- **CPU:** ~2-4% of a core stereo (comparable to Supermassive): 8 modulated reads, 8 damps + 8 bass filters, one 8-pt Hadamard (24 add/sub, no multiplies), 4 input allpasses, one sine LFO read at 8 phase offsets, 2 tap sums. Change-gated coeffs at block rate, linear interp, no oversampling (damping + interp band-limit the tail), ScopedNoDenormals. Freeze is even cheaper. Scale to 4 lines for a low-CPU mode, 12-16 only for 'huge' presets.
- **Viz:** Core-world = a dark rippling basin of water seen top-down: Size widens the pool, Motion animates the watery surface ripples (Mod Shape changes the ripple pattern — sine smooth, random seasick), Damping darkens the depths, Bass Decay adds a deep low swell/undertow, Low Cut thins the surface, Freeze holds the ripples eternally, Width spreads them L/R. Every knob disturbs the water.
- **Back 8:**
  - **Pre-Delay** — Delays wet onset (syncable). 100% = reverb arrives up to a half-note late, an obvious rhythmic gap, vocal-throw style. _(range 0-500 ms (or 1/64-1/2))_
  - **Damping** — Per-line in-loop LP cutoff (how fast highs decay vs lows). 100% = tail goes pitch-black within a fraction of a second, pure sub/low-mid wash; 0% = open bright. _(range ~1.5 kHz (max) - ~18 kHz (open))_
  - **Bass Decay** — Crossover + low-band multiplier — the bass-safe control. Minimum = lows die almost instantly (soak a sub-bass/kick and the low end stays surgically clean); maximum = earth-shaking sub-tail booms far past the mids. _(range 0.1x-2.5x, crossover 80-400 Hz)_
  - **Diffusion** — Input + late in-loop allpass coefficients. 0% = individual fluttering echoes/grain; 100% = a single frictionless glass sheet with zero repeats. _(range 0-100% (g ~0-0.75))_
  - **Mod Rate** — Speed of the multi-phase LFO (depth auto-scaled inversely to stay in tune); shape set by the dropdown. 100% (fast) = obvious lush vibrato/ensemble shimmer; slow = glacial tidal drift. _(range 0.02-8 Hz (or synced))_
  - **Width** — M/S blend of decorrelated output taps (still mono-safe, no null). 0% = folds to dead-center mono; 100% = decorrelated wrap-around wider than the speakers. _(range 0-100%)_
  - **Low Cut** — High-pass on the reverb SEND — stops sub ever entering the loop (complements Bass Decay which bleeds off lows that do enter). Pushed high = thin crystalline wet with zero low buildup over a busy mix. _(range 20-500 Hz)_

### Shimmer

- **Character:** Ether — bright FDN + small grains + octave-up dominant (classic ascending angelic shimmer), Cathedral — long T60, large coprime lines, gentle diffusion (Eno/Lanois hall bloom), Glass — reverse grains + high diffusion, glassy choir-like soft attack, Cloud — dual up+down shift + heavy delay modulation, symphonic swirl, Plate — denser allpass front + shorter delays, tighter vocal/percussive shimmer, Abyss — octave-down + up, dark damping, slow mod, cinematic sub-heavy drift
- **2nd dropdown:** Pitch Mode — the most defining secondary control (exactly what Valhalla/Eventide expose); it changes the CHORD/texture of the ascending cloud more than any knob: Single (classic Eno mode) · Dual (up+down = symphonic) · SingleReverse (reversed grains = glassier) · DualReverse (smoothest, most liquid) · Fifth+Oct (+7 then +12 = major-triad cloud) · Down+Up (-12 & +12 cinematic width) · Bypass (plain reverb).
- **Front (3+Mix):** Shimmer — pitch-shift feedback intensity / shifted-vs-dry blend recirculating in the loop (plain reverb -> fully ascending octave cloud that swallows the source). THE headline macro., Space — scales FDN delay lengths + T60 together (small bright room -> infinite/Freeze pad), Tone — tilt/damping of tail + shimmer top end; sets how HIGH the ascending ladder climbs before it dies, Mix — dry/wet (50% = classic ambient bed, 100% full wash)
- **Algorithm:** The shared 8-line FDN core with a time-domain dual-tap granular pitch shifter placed INSIDE the recirculating feedback path (+12 default). Each pass transposes the signal up, so iterated feedback stacks octave upon octave into an ethereal harmonic cloud that RISES above the source and hangs there — you cannot get that climb from a static reverb. The shifter is granular (one ring buffer, two read taps swept by a sawtooth phasor, each windowed by a raised-cosine that is zero at the splice) NOT a phase vocoder — the vocoder's block latency would become dead loop time and smear the onset, and the granular splice glitches are DESIRABLE (fed decorrelated reverb, the shifter splices quasi-randomly, spreading each sinusoid into a band = the orchestral un-metallic thickness). Stability holds at near-unity feedback ONLY because the octave-up climbs into HF where the per-line damping LP + High-Cut bleed the top so the ladder self-terminates; a DC-blocker stops octave-down/denormal DC accumulating. A tiny parallel feed-forward octave send gives instant onset alongside the building ladder.
- **CPU:** The FDN recursion (~a few hundred flops/sample, sample-by-sample, can't vectorise across feedback) plus the shifter (~2 interpolated reads + 2 table-lookup window mults + a phasor per shifter) = well under 1% of a core; an order cheaper than the CCRMA phase-vocoder. Precompute the raised-cosine window; linear interp; oversample only the pitch read + any loop saturator, never the FDN; ScopedNoDenormals mandatory for the long/infinite tail.
- **Viz:** Core-world = an ascending spectral staircase: the input note spawns a cloud of grains that visibly climbs the frequency axis with each feedback pass (Shift sets the step size/interval, Feedback sets how many rungs and whether it's infinite), High Cut sets the ceiling the climb dies against, Mod Depth makes the rising cloud shimmer/detune, Pitch Blend fades between the dry pitch and the pure ascending choir. Every knob animates the climb.
- **Back 8:**
  - **Feedback (Regen)** — Loop recirculation gain = how many octaves the ladder climbs and how long it sustains. 100% = an infinite self-building ascending WALL that never decays (HF damping self-limits it), a frozen evolving pad; 20% = a short bloom. _(range 20-100%)_
  - **Shift** — In-loop pitch interval, snapped musical. +24 = pure glassy air/whistling harmonics far above; +7 = a fifth-stacked chord cloud; the interval audibly re-harmonizes the whole tail. _(range -24 to +24 st (detented +-12, +7+12, +24))_
  - **Pitch Blend** — Balance of PITCHED vs unpitched signal recirculated. 100% = only pitched content recirculates, the original pitch vanishes into a pure rising octave choir; 0% = normal reverb with a hint of sparkle. _(range 0-100%)_
  - **Decay** — Reverb decay + FDN delay scaling. Infinite = eternal frozen shimmer pad that holds forever; 0.2 s = tight sparkly slap. _(range 0.2 s to Infinite (Freeze))_
  - **Diffusion** — Input allpass g / echo density. 0% = discrete grainy fluttery grains; 100% = seamless glassy wash with no perceptible attack. _(range 0-100%)_
  - **High Cut** — LP in the feedback/return path — how much top survives each pass (also the primary stability control for the octave climb). Low = dark, the shimmer climbs one octave then dies; high = brilliant endless glassy ascent. _(range 1-20 kHz)_
  - **Low Cut** — Highpass in the loop — removes mud, blocks octave-DOWN + DC buildup, keeps feedback stable. Sweeping up lifts the whole tail off the ground; at 800 Hz weightless and airy; at 20 Hz full-bodied. _(range 20-800 Hz)_
  - **Mod Depth** — Randomized chorusing of the FDN delays + grain jitter (raises modal density, decorrelates, kills metallic ring). 0% = static, prone to ring on sustained notes; 100% = lush seasick watery symphonic decorrelation. _(range 0-100% (~+-1 to +-8 samples, 0.05-2 Hz))_

### Convolution

- **Character:** Room — tight studio/live rooms, 0.2-0.8 s, dense early reflections, Chamber — concrete/tile chambers, warm mid-forward tail, Hall — concert/scoring halls, 1.5-4 s, smooth diffuse lush wash, Cathedral — huge stone spaces, 4-10 s, long modal ring, sacred, Plate — sampled EMT-140 metallic sheen, bright dense vocal-glue, Spring — outboard spring-tank IRs, boingy dispersive dub character, Hardware — sampled Lexicon/EMT/AMS digital-unit IRs (vintage algorithmic snapshots), Ambience — short natural spaces for glue without an obvious tail, Reverse — pre-baked reversed IRs for swelling risers, Cosmic / FX — non-space IRs (cabs, formants, metallic/tonal impulses) for sound-design imprinting
- **2nd dropdown:** Space (IR Select) — THE defining control: Character picks the family (Hall/Plate/Cathedral...), this picks the exact captured space/unit, and each selection is a total night-and-day change of identity (e.g. within Hall: 'Vienna Musikverein', 'Boston Symphony', 'Scoring Stage A', 'Dark Gothic Hall'). Every entry triggers an offline IR re-bake so real-time cost is unchanged. Runner-up axes = Engine (Mono | Stereo | True-Stereo LL/LR/RL/RR | Hybrid ER-conv + modulated-FDN tail) or Latency/Quality (Live 0-latency small-block <-> Eco large-block low-CPU).
- **Front (3+Mix):** Size — resamples/stretches the whole IR (25-400%): tiny bright closet -> the same room as a cavernous slower darker cathedral (length + spectral tilt move together, baked offline), Decay — exponential decay window on the IR (10-200%): 10% = gated stab that slams shut; 200% = endless bloom, Damping — master tail brightness via frequency-dependent decay: down = pitch-black felt space; up = glassy tiled bathroom with screaming highs, Mix — equal-power dry/wet, per-IR RMS-normalized so it feels consistent across every space
- **Algorithm:** True impulse-response reverb: y = x * h, where h is a recorded IR of a real space, so the output IS that space (exact reflection timing, level, spectral color, natural frequency-dependent decay — realism no FDN matches). Direct convolution is impossibly heavy, so use NON-UNIFORM PARTITIONED FFT (Gardner/Garcia): small head blocks (256-sample latency) for near-zero latency + geometrically doubling tail blocks (2048, 16384) that are cheap because their big FFTs are amortised and run on a lock-free worker thread. Overlap-save with 2B-size FFTs avoids time-aliasing. The frozen-IR weakness (the same comb repeats forever -> metallic long tails) is cured by Motion (slow sub-Hz pitch modulation), decorrelation, IR morphing, or a hybrid modulated-FDN tail behind a short convolved head. THE CPU/flexibility master-key (Waves IR-1): all IR edits — Size/stretch, Decay window, Reverse, Damping, EQ, Attack, Distance — are baked OFFLINE into a new h on a worker when a knob settles, so the real-time path stays a pure cheap convolution regardless of knob positions; crossfade old->new convolver ~30 ms on swap.
- **CPU:** ~1-3% of a core for a 1-2 s stereo IR via juce::dsp::Convolution baseline; non-uniform multi-FDL is a ~7x win over single-FDL on long IRs. Bake ALL edits offline; cap effective length via Size/Decay; prefer mono/parallel-stereo and only spin up true-stereo's 4 convolutions when Width is high, SHARING input FFTs (L feeds LL+LR, R feeds RL+RR = 2 extra MAC sets, not 2 extra FFTs); real-FFT (B+1 bins), SIMD complex-MAC, tail FDLs on a background thread, ScopedNoDenormals, RMS-normalize every IR on load, safety limiter on the wet.
- **Viz:** Core-world = the actual IR waveform/decay envelope drawn as the space's fingerprint: Size stretches it wider/darker, Decay truncates or extends the tail envelope, Attack fades/skips the front, Reverse flips it, Distance slides the balance between the early-reflection spike cluster and the late tail, Damping darkens the high end of the drawn tail, Density smears discrete spikes into a smooth curve, Motion makes the tail shimmer. Selecting a new Space redraws the whole fingerprint. Every knob reshapes the visible IR.
- **Back 8:**
  - **Pre-Delay** — Silent gap before the wet (syncable). 100% = a fully detached slap arriving a beat later, not a room glued to the note. _(range 0-250 ms (or 1/64-1/2))_
  - **Attack (IR Start)** — Moves the play-head into the IR + fades the onset, skipping the direct hit and early reflections. 100% = the sharp ER attack is gone entirely, sound emerges from nowhere as a soft diffuse-only swell. _(range 0-100% of pre-tail length)_
  - **Width** — Mono-summed -> parallel stereo -> true-stereo 4-path matrix -> decorrelated super-wide. 0% = dead-center mono point; 200% = fully wrapped-around field with walls outside the speakers. _(range 0-200%)_
  - **Motion** — Depth of slow tail modulation (pitch/delay movement + chorus on the hybrid FDN tail) that de-correlates the repeating comb — the anti-frozen/anti-metallic control. 0% = frozen ringing metallic drone; 100% = lush seasick chorused cloud that never sits still. _(range 0-100% (sub-Hz to ~2 Hz))_
  - **Reverse** — Crossfades to a pre-baked reversed IR. 100% = every hit is preceded by a ghostly reverse-swell rushing INTO it (psychedelic sucked-backwards reverb). _(range 0-100% (forward -> reversed))_
  - **Distance (ER<->Tail)** — Balance of early reflections vs late diffuse tail. Fully Near = intimate up-front room you can touch; fully Far = source at the back of a huge hall, all wash, no definition. _(range Near (ER-only) <-> Far (tail-only))_
  - **Low Cut** — High-pass on the WET only, clearing rumble/mud so big IRs stay usable. At 1 kHz the tail becomes a thin telephone/AM-radio wash with all weight stripped. _(range 20 Hz-1 kHz)_
  - **Density (Smear)** — Allpass diffusion smoothing of the IR. Low = discrete machine-gun reflection clicks/grain; high = the taps fuse into one seamless silky glass cloud. Tames sparse/metallic IRs. _(range 0-100%)_

## Dramaticism

Calibration rule: every one of the 8 back knobs must be night-and-day at its extremes, and 100% must be UNMISTAKABLE — the sound has to match the number. Concretely: (1) Decay/Time knobs must reach true Freeze/infinite at max (a self-sustaining drone you can play over), not merely 'long'. (2) Damping/Tone extremes must span pitch-black-felt to glassy-endless-shimmer — a full LP sweep, not a subtle shelf. (3) Diffusion/Density must audibly flip grain->glass (you can COUNT discrete echoes at 0%, zero individual echoes at 100%). (4) Modulation depth must go from static/metallic-ring-exposed to overtly seasick/detuned — modulation is the single biggest 'cheap box vs Lexicon' tell, so voice it generous. (5) Bass/Low-Decay must swing from surgically-tight (soak a sub-bass and the low end stays clean) to thunderous-booming-outlasts-everything. (6) Width must collapse to dead-center mono AND blow past the speakers, mono-safe (no null). (7) Pre-Delay max must open an OBVIOUS rhythmic gap between dry and wet. (8) Signature/identity knobs get the most theatrical range: Plate's Dispersion (flat -> steel-plate boing whip), Spring's Shake (still -> crashing metallic storm), Digital's Chorus/Mod (dead-still cold -> lush swirling shimmer), Shimmer's Feedback (short bloom -> infinite ascending wall), Convolution's Reverse (forward -> fully sucked-backwards). Front macros are super-controls that ride several back params in a musically-voiced curve; keep front label names DISTINCT from every back-knob label to honor the no-doubles law (e.g. front 'Tone' vs back 'HF Damping', front 'Chorus' vs back 'Mod Depth/Rate', front 'Motion' vs back 'Mod Rate'). And the hard rule: every knob that changes the SOUND must change the core-world VIZ — no dead-knob-to-scope gaps.
