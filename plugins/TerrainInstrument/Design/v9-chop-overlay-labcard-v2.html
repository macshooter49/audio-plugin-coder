What changed from v8 lab card

  • Fonts kept Terrain-default — -apple-system + ui-monospace, uppercase letter-spaced category labels. No serif experiment.
  • Full ADSR drawn as one continuous shape — three draggable handles: A (drag X = attack ms), DS (drag X = decay ms, drag Y = sustain level), R (drag X = release ms).
  • Sustain hold region shown as a dashed purple plateau between DS and R — visualises that the level is held during note-hold.
  • Volume added — new per-chop control next to Pitch + Stretch. Backend needs a new Slice.volume field + native fn.
  • No parameter text labels — the glyph plus the numeric value is enough; tooltip on hover for first-timers.
  • Pitch glyph redesigned — mini staff with a positioned dot (was: ambiguous tuning fork).
  • Stretch glyph redesigned — accordion bars (was: generic waveform).
  • Both new glyphs animate subtly at idle — pitch dot bobs vertically, stretch bars breathe horizontally, volume bars pulse asynchronously. Animation pauses on hover so the user sees the real value clearly.

If you want the ADSR letters (A · D · S · R) inside the canvas dropped, say so — they're at low opacity and only there to help first-timers read the curve shape.
