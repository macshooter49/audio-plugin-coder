Chop overlay — three directions

The v7 panel reads too generic — uppercase letter-spaced labels, white-dot sliders, monospace pseudo-data. Those are the AI-app-shell trifecta. LESE's language (Eigen / Strum / Hikari) does the opposite: arc-knobs with custom glyphs inside, sentence-case labels, one accent on tonal grayscale, illustrated/engineered feel. Each direction below keeps the v7 idea you liked — floating modal, mode emblems, per-chop ADSR — but rebuilds the visual language so it doesn't look like every other AI-built panel on the planet.

Core move shared by all three: the emblems ARE the knobs. Drag vertically on a glyph to change its value, scroll-wheel works too, the thin arc around it shows where you are in the range. No more slider bars.

What changed across all three

No more sliders. Each parameter glyph IS the knob: drag vertically or scroll wheel to change value. The thin arc around the glyph shows where you are in the range. Hover surfaces the tooltip you already have for the rest of the UI.

Sentence-case labels. "attack" not "ATTACK", "chop iii" not "CHOP 03". This single change kills more of the "AI" feel than any other tweak.

Single accent on tonal grayscale. Terrain purple does all the work — no extra greens / pinks / oranges. The danger state on the delete action is the only exception.

Serif touches. Roman numerals + a soft serif for the chop number ("Iowan Old Style") read drafted rather than rendered. Every number stays monospaced — that's still Terrain.
