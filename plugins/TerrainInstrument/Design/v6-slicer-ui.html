VISUAL LANGUAGE LOCK-IN

  • Slicer panel: top-center floating bar, ghost-glass (3.5% white tint, blur 8px), only visible in SLICE primary mode. Fades in 220ms when SLICE activates.
  • AUTO: single click → background-thread transient detection → replaces slice list. Inline button.
  • GRID: dropdown with 4 / 8 / 16 / 24 / 32. Click number → equal-divides sample into N slices.
  • Chop count: shows current count (e.g., "12 CHOPS"). Purple-400 colour to draw the eye.
  • Sub-mode pills (CHOP / CHROMATIC): same ghost-glass pill language as bottom strip. Tertiary control, only relevant in SLICE mode, so it lives WITH the slicer panel rather than the bottom strip.

WAVEFORM INTERACTION

  • Markers: 1px purple-400 vertical lines, span the full waveform vertical area. Index label at top in a small dark pill.
  • Slice body hover: 7% purple wash. Tells the user what's clickable.
  • Active slice (CHROMATIC sub-mode): 18%→10% purple gradient + 1px purple borders left/right. Critical to see which slice gets the chromatic playback. Always shows in CHROMATIC; never in CHOP.
  • Slice badge on hover: small floating tag showing pitch offset and reverse state, e.g., "+5st" or "REV +0st". Positioned above the slice. (Implementation: tooltip-style, only on hover or active.)

GESTURES (locked for v0)

  • click on slice body: CHOP → audition. CHROMATIC → set as active.
  • click + vertical drag > 3px: adjust slice pitch offset (drag up = pitch up). Threshold prevents drag from eating audition clicks.
  • right-click on slice body: context menu — Reverse / Reset Pitch / Delete Chop.
  • shift+click on slice body: alt-audition (always plays even in CHROMATIC mode without changing active).
  • Future v0.5: drag boundary marker = resize slice (with zero-crossing snap on by default).
  • Future v0.5: double-click empty waveform area = insert new marker at click position.

PITCH MODE STATE (for reference)

When user toggles back to PITCH mode, the top-center slicer panel fades out (220ms), the waveform markers vanish, and the hero looks identical to the current ghost-glass commit. No surprise — slicer chrome is fully contained in SLICE mode.
