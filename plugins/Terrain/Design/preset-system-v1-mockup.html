Selection — buttons (pills, chips, Load, the heart) use the four mode tiles' rule: an outline, transparent inside; selected turns it purple with white letters. Selection menus (banks, authors, rows, the quick menu): hover washes purple, the selected line's words turn purple. Quick menu — click the preset name. Left column is banks (click one), right column is that bank's presets grouped by type; ‹› step inside the current bank. Browser — single click selects and auditions, double-click or ↵ loads and closes, ↑↓ step, esc closes. Click Name, Carries, Type or Style to sort; again to flip. Right-click a User preset for rename / delete. Saving — the + in the header opens Save (overwrites the current user preset, ⌘S) · Save as… (⇧⌘S) · Export preset… (a .terrain file). Right-click any row for Save as…, Overwrite with current, Export preset… Editable — the + at the end of Type and Style adds a word; right-click a chip to rename or remove it, and every preset re-files itself. At save, type into Bank (an existing name joins it, a new one creates it), Author, Type and Style. Right-click any bank you made or imported to rename, export or remove it. Search reads names, types, styles, effects, authors and banks; every word must match. Carries — wavetables · one-shots · IRs · flow cards · LFO shapes · nodes. A preset with nodes is an environment; loading one greys the window and shows the bar. Notes — click under Notes in the inspector and type; it saves with the preset and search reads it. The Type and Style strips scroll sideways when they overflow.
